# Pulumi Qube Keycloak Resource Provider

The Pulumi Qube Keycloak Resource Provider lets you manage Realm resources in Keycloak Server.

## Installing

This package is available for several languages/platforms:

### Node.js (JavaScript/TypeScript)

To use from JavaScript or TypeScript in Node.js, install using either `npm`:

```bash
npm install @raushan606/qeycloak
```

or `yarn`:

```bash
yarn add @raushan606/qeycloak
```
